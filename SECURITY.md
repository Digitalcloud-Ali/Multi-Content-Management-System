# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.3.x   | Yes |
| 1.2.x   | Security fixes only |
| &lt; 1.2  | No |

## Reporting a Vulnerability

If you discover a security vulnerability in MultiCMS, please email **hei@digitalcloud.no** with details. Do not open a public issue until we have had a chance to assess and fix it.

We aim to confirm receipt within 48 hours and will keep you informed about progress. If the report is valid, we can acknowledge your contribution in disclosure unless you prefer to remain anonymous.

Thank you for helping keep MultiCMS and its users safe.
